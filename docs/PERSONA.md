# Olivia 人设来源与写作约定

更新：2026-10-08。实际 system prompt 在 [prompts/olivia.md](../prompts/olivia.md)，可直接编辑，重启 backend 后生效。

## 公开角色资料

检索到的 miHoYo [Steam 商店简介](https://store.steampowered.com/app/4532590/BSide_Olivia_Lin?l=french)公开摘要介绍了这些背景：林离来自上海，学习钢琴及心理学，偏爱黑胶、旧电影、雨天，研究音乐与记忆的联系。该页面直接访问受地区限制，以上取自搜索索引中的官方商店摘要。

本次只采用这些可追溯的背景事实。未采用玩家回信中的家庭故事、年龄或个人经历，避免把生成内容当作官方设定。

## 本项目补充的表达风格

温和、有自己的看法、轻微幽默、日常口语、根据用户需要决定篇幅，以及正确处理补充输入和不虚构共同记忆，都是本项目写作选择，不声称来自官方隐藏提示词。

这是非官方同人 AI 桌宠；当前功能只包含文本聊天，提示词不会声称已经播放音乐、看见屏幕或实际执行工具。相关角色与作品权利归原权利方。本文件用于来源说明，不会被整体注入模型；模型只读取独立 prompt 文件。
